## Overview

Task List adds a persistent in-game note panel where you jot down build targets, mark them complete, and share the list in multiplayer, replacing sticky notes and alt-tab text files.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Task List** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Persistent Notes** | Task list saved with the game file and survives session restarts |
| **Completion Marks** | Checkbox each task and it moves to a completed archive section |
| **Multiplayer Sync** | All players on the server see and edit the same shared task list |
| **Rich Text** | Supports item icons and color tags inline with task descriptions |
